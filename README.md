# 🌊 心情漂流瓶

> 國立臺中科技大學 資訊管理系 畢業專題

在這個凡事都要按讚、留言、回覆「已讀」的年代，我們想提供一個可以好好喘口氣的地方。

**心情漂流瓶**是一個以「漂流瓶」為主題的匿名社交網站。使用者可以把心情寫進瓶子裡丟向大海，也可以隨手撈起一個陌生人的瓶子，看看遠方的某個人今天過得如何。不必經營形象，也不必在意追蹤數，說出想說的話就好。

當然，大海也需要有人維護秩序。每一個瓶子在出海之前，都會先經過 AI 海巡的審核與分類，確保這片海域溫暖、友善，而且沒有漂浮垃圾。

## ✨ 功能介紹

### 🍾 漂流瓶社群

本網站的核心功能，也是整片海域的日常。

- **丟瓶子**：發表心情文章，可自由選擇匿名或具名，並加上分類標籤。拿不定主意時，也可以在瓶子裡附上投票，讓大家幫忙決定晚餐吃什麼。
- **撈瓶子**：隨機撈起一個別人的瓶子，每一次都是一場不期而遇。
- **互動**：按讚、收藏、留言與回覆留言；若撈到不當內容，也可以直接檢舉。
- **探索**：透過關鍵字搜尋，或查看熱門瓶子排行，了解最近大家都在聊些什麼。
- **社交**：追蹤欣賞的使用者、查看粉絲與追蹤清單，並透過通知掌握最新動態。
- **封鎖**：封鎖後，雙方將互相看不到對方的文章，且系統不會通知對方。海很大，彼此各自安好即可。

### 🤖 AI 輔助

- **AI 內容審核**：新發表的瓶子會交由 AI（Google Gemini）自動審核並分類，違規內容將無法出海。
- **AI 特助聊天室**：半夜睡不著、有話想說卻找不到人時，AI 特助隨時在線，而且不會已讀不回。

### 🛡️ 帳號與安全

雖然是輕鬆的網站，安全措施可一點也不馬虎。

- 註冊須經 Email 驗證，並提供忘記密碼與重設密碼功能
- 密碼以 bcrypt 雜湊後儲存，登入採用 JWT 驗證
- 註冊與寄信相關 API 依 IP 限制請求頻率，防止濫用
- 客服中心：遇到問題可隨時回報，並可附上圖片說明

### 🧑‍💼 管理後台

- **會員管理**：查看會員資料、停權或封禁帳號、調整管理員權限
- **內容管理**：審核瓶子、處理檢舉、管理留言
- **客服回覆**：查看並處理使用者回報的問題與附圖

## 🏗️ 系統架構

```
┌─────────────────┐      ┌──────────────────────┐      ┌────────────┐
│  前端 (frontend) │ ───▶ │  後端 API (backend)    │ ───▶ │  資料庫     │
│  GitHub Pages    │ ◀─── │  Express + Socket.IO  │      │  (Prisma)  │
└─────────────────┘      └──────────────────────┘      └────────────┘
                                   ▲
                                   │ 取得待審核瓶子 / 回傳審核結果
                          ┌────────┴─────────┐
                          │  AI 審核 (AI)      │
                          │  Python + Gemini  │
                          └──────────────────┘
```

| 部分 | 使用技術 |
|---|---|
| 前端 | HTML / CSS / JavaScript，透過 GitHub Actions 自動部署至 GitHub Pages |
| 後端 | Node.js、TypeScript、Express 5、Prisma、Socket.IO、JWT、Multer、Nodemailer |
| AI | Python、Flask、Google Gemini API |

## 🚀 本機開發

### 後端

```bash
cd backend
npm install
# 在 backend/ 建立 .env，設定 DATABASE_URL 等環境變數
npx prisma migrate dev
npm run dev
```

### AI 審核服務

```bash
cd AI/src
# 在 AI/src/ 建立 .env，設定 Gemini API 金鑰、BACKEND_URL 等環境變數
python ai_db_worker.py
```

### 前端

前端為純靜態網頁，以瀏覽器或 VS Code Live Server 開啟 `frontend/index.html` 即可預覽。推送至 `main` 分支後，GitHub Actions 會自動完成部署。
